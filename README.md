# Puneet Mishra — Portfolio (Next.js 14 + Tailwind + Framer Motion + Lenis)

## Run in VS Code
1. Open this folder in VS Code, then open the terminal (Ctrl + `).
2. `npm install`
3. `npm run dev` → open http://localhost:3000

## Add your photo
Put a portrait (4:5 ratio, PNG) at `public/me.png`. Until then the hero shows a "PM" placeholder.

## Edit content
Everything (text, projects, links, skills) is in `lib/data.ts`.
Colors are in `tailwind.config.ts`.

## Deploy
Push to GitHub and import the repo on vercel.com (free), or run `npm run build`.
